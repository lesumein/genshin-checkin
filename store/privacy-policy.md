# 개인정보처리방침

이 문서는 Sumi Lab이 만든 안드로이드 앱 "원신 출첵"(패키지 `kr.sumi.checkin`, 이하 "앱")이 어떤 정보를 다루는지 설명합니다.
앱은 HoYoverse(COGNOSPHERE)와 관계없는 비공식 도구입니다.

## 앱이 저장하는 정보
- **HoYoLAB 로그인 쿠키**: 사용자가 앱 안의 HoYoLAB 페이지에서 직접 로그인하면 생기는 로그인 쿠키(`ltoken_v2`, `ltuid_v2` 등). 출석체크·보충 출석·리딤 코드 입력 요청에 씁니다.
- **출석·보상 기록**: 마지막 출석 결과, 누적 출석 일수, 받은 리딤 코드, 게임 캐릭터의 닉네임·서버·UID.
- **실시간 메모**: 레진·탐사 파견·주전자 동전·일일 의뢰 현황. 메인 화면·위젯 표시와 레진 알림에 씁니다.
- **홈 꾸미기(로비형을 고른 경우)**: 최애 캐릭터, 내 캐릭터 목록(이름·원소·레벨·호감도·운명의 자리), 캐릭터 그림, 사용자가 고른 사진(화면 크기로 줄인 사본). 사진은 앱 안에만 저장하고 어디에도 보내지 않습니다.
- 앱은 **아이디와 비밀번호를 저장하지 않습니다.** 로그인은 HoYoLAB 페이지에서 사용자가 직접 합니다.

이 정보는 **기기 안의 앱 전용 저장소에만** 있습니다. 다른 앱은 읽을 수 없고, 기기 백업·기기 이전 대상에서도 빠져 있습니다.
앱 안의 "이 계정 로그아웃"을 누르거나 앱을 지우면 함께 지워집니다.

## 앱이 통신하는 곳
- **HoYoLAB 서버**(`*.hoyolab.com`, `*.hoyoverse.com`): 출석체크, 보충 출석, 보상 내역, 리딤 코드 입력, 캐릭터 목록·실시간 메모·전적(내 캐릭터 목록) 조회. 사용자의 로그인 쿠키를 함께 보냅니다. HoYoLAB 전적 기록의 '실시간 메모'가 꺼져 있으면, 사용자에게 물어 동의한 경우에만 이 설정을 켭니다. 진행 중인 이벤트 목록과 배너 그림은 로그인 정보 없이 받고, 이벤트를 누르면 앱 안 화면에서 로그인 쿠키로 그 페이지를 엽니다.
- **HoYoLAB 위키**(`wiki.hoyolab.com`의 공개 자료): 로비형 홈에서 최애 캐릭터의 그림과 대사, 최애로 고를 수 있는 캐릭터 목록(이름·원소·얼굴 그림)을 받고, 말풍선이나 캐릭터를 누르면 그 대사의 음성(고른 언어)을 받아 재생합니다. 받은 음성은 지금 최애·언어 것만 앱의 임시 저장 공간에 두고 다시 쓰며, 홈 꾸미기에서 지울 수 있습니다. 복각표의 캐릭터 얼굴 그림과, 알림에 붙일 최애 캐릭터의 세로 그림도 받습니다(얼굴 둘레만 잘라 기기에 저장합니다). 로그인 정보는 보내지 않습니다. 그림·대사의 저작권은 HoYoverse에 있으며 앱에 포함하지 않고 기기에만 저장합니다.
- **구글 글꼴(구글 플레이 서비스)**: 로비형 홈을 켜면 이름·대사에 쓸 나눔명조 글꼴을 기기의 구글 플레이 서비스를 통해 받습니다. 글꼴 이름 외에 앱의 정보는 보내지 않습니다.
- **원신 Fandom 위키**(`genshin-impact.fandom.com`): 공개된 리딤 코드 목록을 읽습니다. 로그인 정보는 보내지 않습니다.
- **Sumi Lab 안내 사이트**(`apps.sumi.kr`, GitHub Pages): 복각표 자료(캐릭터별 마지막 픽업 버전), 리딤 코드 목록, 앱 설정(공식 그림 사용 여부), 캐릭터 그림의 얼굴 위치를 받습니다. 아무 정보도 보내지 않고 파일만 받습니다. 일반 웹 요청처럼 접속 기록(IP 등)은 GitHub이 처리합니다.

이 앱은 정보를 받는 개발자 서버가 없으며, **이 앱의 어떤 정보도 개발자에게 전송되지 않습니다.**
광고, 분석 도구, 크래시 리포트 도구를 쓰지 않습니다.
앱이 비정상 종료되면, 사용자가 기기에서 진단 정보 공유를 허용한 경우 Google Play가 기기 모델·Android 버전·오류 위치 같은 통계를 개발자에게 보여 줄 수 있습니다. 이 통계는 앱이 아니라 Google Play가 수집하며 Google 개인정보처리방침을 따릅니다.

## 권한
- 인터넷: HoYoLAB과 통신
- 알림: 출석 결과·보충 출석·리딤 코드·레진·탐사 파견·주전자 동전·기다리는 캐릭터 픽업 알림
- 네트워크 상태 확인: 인터넷이 연결됐을 때만 예약된 출석·리딤 작업을 돌리기 위해
- 정확한 알람, 부팅 완료 수신, 배터리 최적화 예외 요청: HoYoLAB의 날짜가 바뀌는 시각(한국 시간 새벽 1시) 직후에 자동으로 출석하기 위해
- 원신 설치 여부 확인: '원신 켜기' 버튼을 보여 주기 위해 원신(플레이 스토어판·갤럭시 스토어판)이 깔려 있는지만 확인합니다. 다른 앱 목록은 보지 않습니다.
